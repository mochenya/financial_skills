# 财联社电报网页接口研究

本记录基于 2026-11-16 财联社电报网页的 Chrome DevTools 抓包、网页 JavaScript 和少量实际请求。接口未见公开契约，字段、行为、签名、限流与可用性均可能变化；下文中的实测结果不代表全部合法参数或长期保证。日常使用直接运行脚本；调整接口适配、排查上游变化时再读本文。

## 电报列表

网页地址：<https://www.cls.cn/telegraph>。首屏会请求 `/api/cache?name=telegraph`；点击“加载更多”时，网页先尝试缓存接口 `/api/cache?name=telegraph&lastTime=...&rn=20`，缓存数量不足时再调用：

```http
GET https://www.cls.cn/v1/roll/get_roll_list
```

例如：

```text
app=CailianpressWeb&last_time=1794819300&os=web&refresh_type=1&rn=20&sv=8.7.9&sign=d52e26f813937bf362e5281bce0d827d
```

| 参数 | 观察或实测 |
| --- | --- |
| `app`、`os`、`sv` | 网页当时使用 `CailianpressWeb`、`web`、`8.7.9`。 |
| `last_time` | 秒级 Unix 时间戳，作为分页时间游标。 |
| `refresh_type` | 页面加载历史时传 `1`。一次测试传 `0` 返回游标之后较新的数据，完整语义尚未验证。 |
| `rn` | 页大小；实测 5、20、30、40、50 分别返回相应数量，99 和 100 返回空数组，不能据此确定上限。网页和本脚本使用 20。 |
| `category` | 网页可传分类；实测 `red`、`hk_us`、`fund` 返回结果，未全面核对枚举及其语义。本脚本不传。 |
| `id` | 网页源码显示 `category=dynamic` 时传话题 ID，未实测，本脚本不传。 |
| `sign` | 参数签名，下面详述。 |

HTTP 200 不代表业务成功。缺失或错误签名、改变参数却沿用旧签名，实测响应 `errno: "10012"`、`msg: "签名错误"`。成功响应 `errno` 为数字 `0`，列表位于 `data.roll_data`；脚本校验业务状态、数据形状及自身依赖字段。请求不显式带登录 Cookie 在测试时成功；不能保证其他时段、网络环境或接口也如此。

### 实际字段样例

以下节选自同次抓包，省略了正文及其余字段：

```json
{
  "errno": 0,
  "msg": "",
  "data": {
    "roll_data": [
      {
        "id": 2535574,
        "ctime": 1794819842,
        "title": "",
        "content": "《科创板日报》16日讯，香港交易所信息显示，花旗集团在恒瑞医药H股的持股比例于11月10日从6.00%降至5.29%。",
        "reading_num": 3554,
        "comment_num": 0,
        "share_num": 0,
        "level": "C",
        "subjects": [{"subject_id": 1097, "subject_name": "港股动态"}]
      }
    ]
  }
}
```

`ctime` 对应北京时间 2026-11-16 17:04:02；相同时刻页面显示“阅 3554”。页面对大数会展示为 `W`，接口返回原始整数。`reading_num`、`comment_num`、`share_num` 是抓取时的数值，统计口径和历史快照未核实。`title` 可能为空，`content` 可能以 `【标题】` 开头；`brief` 可短于正文。

其他观察到的字段包括 `stock_list`（部分关联股票）、`assocArticleUrl`（部分原文或公告链接）、`images`、`audio_url`、`recommend`、`level`、`modified_time` 等。首屏缓存和历史列表的字段集合不同；不能假定每个入口都提供同一组字段，也不能仅凭字段名推断完整枚举和语义。上游列表实测混有 `type=20021` 的研报条目；普通电报样本的 `type` 为 `-1`。脚本按列表原样返回，未按 `type` 过滤。

## 签名

网页当前实现对参数键名排序，按 `key=value` 用 `&` 连接，先计算 SHA-1 十六进制字符串，再对该字符串计算 MD5 十六进制字符串。对于上述列表请求，签名前为：

```text
app=CailianpressWeb&last_time=1794819300&os=web&refresh_type=1&rn=20&sv=8.7.9
```

SHA-1 后再 MD5 的结果是 `d52e26f813937bf362e5281bce0d827d`。本脚本只针对列表请求的简单 ASCII 标量参数实现并实测；网页中数组、对象和非 ASCII 参数的序列化规则不能直接由此推广。签名算法和客户端版本常量可能变化，遇到签名错误应重新检查网页请求和代码。

## 时间窗口与分页

`refresh_type=1` 时，以下边界经单条样本验证：游标为 `1794819842` 时不包含 `ctime=1794819842` 的记录，游标加一则包含。因此该样本表现为 `ctime < last_time`。未发现或验证同时传起止时间的接口参数；脚本以查询时刻开始向前分页，在本地筛选 `起始时间 <= ctime <= 查询时刻`。

游标只有秒级：如果一页恰好在同秒多条记录中截断，下一页直接使用最早 `ctime` 可能漏掉同秒数据。脚本以 `最早 ctime + 1` 重叠翻页、按 ID 去重；如果满页且最早时间不再推进，报错提示无法确认完整性。若同一秒记录数达到单页容量，单凭此时间游标不能保证继续翻过该秒。内容修改、删除、延迟出现及上游过滤也会影响完整性。

`--limit` 先按发布时间选择最近 N 条，再按用户所选字段排序；`--since` 先筛选起始时刻至查询时刻的记录再排序。平均阅读速度为抓取到的 `reading_num` 除以从发布时间到查询开始时间的分钟数，不代表区间新增阅读；各页获取时间可能不同。

## 网页日期搜索

网页选择日期时调用 `POST https://www.cls.cn/api/csw`，曾观察到请求体：

```json
{"lastTime":1794758399,"keyword":"","category":"","os":"web","sv":"8.7.9","app":"CailianpressWeb"}
```

选择 2026-11-15 时 `lastTime` 是北京时间当天结束时刻。该次响应包含 `total` 和 `list`，列表每项含 ID、时间、标题、正文和分类，但没有 `reading_num`；因此脚本没有采用此接口。搜索分页及更多参数未系统验证。
